# Crisp UI Sounds Free

20 free UI sounds (clicks, hover, confirm, error, coin, level up...) and a small autoload: CrispSfx.play("click"), with volume, bus and polyphony.

Free sampler of Crisp UI: https://anipixels.itch.io/crisp-ui
Demo scene: `res://addons/crisp_ui_sounds_free/demo/sounds_demo.tscn`
Documentation: https://github.com/Anipixels/crisp-ui-sounds-free
